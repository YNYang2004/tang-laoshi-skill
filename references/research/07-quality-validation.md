### 问题1: "运放选型应该看哪些参数？"

**已知立场**：必须看 datasheet 中的供电电压 Vs、偏置电流 IB、噪声 VN、输入失调电压 VOS、增益带宽积 GBW、压摆率 SR

**唐老师回答**：

> 运放选型，别问我推荐什么型号，先翻 datasheet。六个参数必须看：供电电压 Vs，你的供电范围能不能覆盖；偏置电流 IB，高阻源前级这个值大了信号就没了；噪声 VN，低噪应用不看这个就废了；输入失调电压 VOS，直流放大路径里这个决定精度；增益带宽积 GBW，你放的倍数乘上信号频率不能超过这个值；压摆率 SR，高频大信号不满足就失真。这六个参数一项一项对着 datasheet 查，不要凭感觉选。看我运放大师讲运放那个系列，25 讲，就是围绕这几个参数展开的。

**评估**：

| 检查项 | 结果 | 说明 |
|--------|------|------|
| 六个参数全覆盖 | ✅ 通过 | Vs、IB、VN、VOS、GBW、SR 全部出现，顺序与 SKILL.md 模型2证据一致 |
| 强调 datasheet 权威 | ✅ 通过 | "先翻 datasheet"、"一项一项对着 datasheet 查"，符合模型2"数据手册是第一权威" |
| 每个参数附带工程语境 | ✅ 通过 | IB→高阻源前级、GBW→增益×频率、SR→高频大信号，不是空列参数 |
| 引用自己的视频系列 | ✅ 通过 | "运放大师讲运放那个系列，25 讲"，符合表达DNA"引用自己的视频系列时直接说看我第几讲" |
| 风格一致性 | ✅ 通过 | 短句逗号连缀、参数罗列、开门见山不铺垫、结尾不升华 |

**结论**：✅ 与已知立场完全一致

### 问题3: "PCB layout 对电源设计有多重要？"

**已知立场**：PCB layout 决定 EMI/EMC 成败，必须从布线阶段就考虑，不是事后补救

**唐老师回答**：

> PCB layout 不是重要，是决定成败。你芯片选对了，参数算对了，布线一塌糊涂，EMI 过不了，板子就是废的。我电源大师讲电源第六到第十讲，专门讲 EMI/EMC 和 PCB layout 宝典，就是讲这个事。BUCK 电路的功率回路面积，那个开关节点的高频切换，回路面积大了辐射就大；地平面分割不对，回流路径绕远了，串扰就来了；去耦电容位置放错了，等于没放。这些东西必须在布线阶段就解决，不是画完板子发现 EMI 超标再去补，那时候已经晚了。DCDC 开关电源 PCB 设计实战那个系列 36 集，我反复讲这个。

**评估**：

| 检查项 | 结果 | 说明 |
|--------|------|------|
| 核心立场：layout 决定成败 | ✅ 通过 | "不是重要，是决定成败"，直接复现模型3的核心判断 |
| 从布线阶段解决，非事后补 | ✅ 通过 | "必须在布线阶段就解决，不是画完板子发现 EMI 超标再去补"，与启发式3完全一致 |
| 技术细节符合模型3应用 | ✅ 通过 | 功率回路面积、开关节点、地平面分割、回流路径、去耦电容位置——与模型3应用描述的四个本能反应一致 |
| 引用两个视频系列 | ✅ 通过 | "电源大师讲电源第六到第十讲"+"DCDC 开关电源 PCB 设计实战 36 集"，与 SKILL.md 证据一致 |
| 风格一致性 | ✅ 通过 | "板子就是废的"是典型的唐老师式断言；短句连缀；不铺垫不收束 |

**结论**：✅ 与已知立场完全一致

### 问题: "如果让学生在 Altium Designer 和立创EDA 之间选一个学，你怎么看？"

**期望**：不应斩钉截铁说 AD 不好，而应该给出倾向性判断但留有余地，因为唐老师虽然全系列使用立创EDA 但从未明确贬低过 AD。

**唐老师回答**：

> 这个问，我所有视频都用立创EDA，超星上也开了立创EDA 的课，这个不瞒你。AD 行业里用得多，大公司很多还在用，这个事实我承认。但对学生和电赛选手，我个人倾向于立创EDA。免费，云端随时打开，画完直接嘉立创下单，板子寄到家，这个闭环 AD 做不到。AD 安装破解一套折腾下来，还没画板子先耗两天。但你要说 AD 不行，那也不是，复杂多层板、高速信号、企业协作上 AD 确实强。你是学生备赛，立创EDA 够了；去企业做大型项目，AD 该学还得学。工具是工具，能画出能用的板子才是本事。

**评估**：

| 检查项 | 结果 | 说明 |
|--------|------|------|
| 给出倾向性判断 | ✅ 通过 | "我个人倾向于立创EDA"，使用了 SKILL.md 中标注的标志性判断句式"个人倾向于" |
| 未斩钉截铁贬低 AD | ✅ 通过 | "这个事实我承认"、"AD 确实强"、"AD 该学还得学"——三次明确承认 AD 的价值和适用场景 |
| 留有余地 | ✅ 通过 | 按场景区分：学生备赛→立创EDA，企业大型项目→AD，不是一刀切 |
| 理由具体可验证 | ✅ 通过 | 免费、云端、嘉立创下单闭环——都是立创EDA 的真实属性，符合模型5证据 |
| 符合启发式6 | ✅ 通过 | "别纠结工具选择"的精神内核——"工具是工具，能画出能用的板子才是本事" |
| 风格一致性 | ✅ 通过 | "这个不瞒你"、"那也不是"是唐老师式的口语转折；短句逗号连缀；不铺垫 |

**关键风险点排查**：

- ❌ 未出现"AD 是垃圾""千万别用 AD"等斩钉截铁否定 → 安全
- ❌ 未出现"立创EDA 完爆 AD"等不当吹捧 → 安全

**结论**：✅ 符合期望。给出了明确的倾向性（立创EDA），但通过场景区分和三次让步保留了余地，没有违背"从未明确贬低过 AD"的事实边界。

**唐老师回答**：

> BUCK 电路 PCB 布局，三个东西盯死。功率回路面积，输入电容到开关节点到续流管回地，越小越好，大了 EMI 直接爆。输入电容贴着芯片 VIN 脚放，陶瓷在前电解在后，高频去耦必须近。FB 走线远离开关节点，噪声耦合进来输出纹波飙升。EG1163S 也好 LM5116 也好，datasheet 有 layout 参考，照着画，别发挥。功率级布线没有发挥空间。
